## 🏎️ Why Formula 1?

It started when I was **4 years old**.

*Cars* (2006). Lightning McQueen. The roar of engines, the blur of speed, the drama of competition. To most kids, it was a movie. To me, it was a **calling**.

That spark never faded. It grew into a passion for real racing, for the engineering stories behind every tenth of a second. I started watching **Formula 1** and became obsessed — not just with who won, but *how*. The aerodynamics, the telemetry, the tire strategies, the relentless iteration.

Formula 1 is the **pinnacle of applied engineering**. Every component is optimized to the atom. Every millisecond is fought for with data. It's a sport where the best engineers in the world compete through machines, and there is nowhere else I want to be.

I've been building toward this my entire life — now it's time to show what I can do.

## 🔬 Projects

### 🏎️ Motorsport Vehicle Telemetry Logger
> *Real-time data acquisition for performance analysis — the kind of system that wins races.*

Designed and built a **vehicle telemetry data logger** capable of capturing real-time sensor data from a moving vehicle. The system integrates embedded hardware with custom firmware to sample, encode, and log critical performance metrics — speed, acceleration, temperature, and more. Data is structured for post-session analysis, mimicking the pipeline used in professional motorsport environments. Built with a performance-first mindset: low latency, high reliability, and clean data output.

**Stack:** C/C++, Embedded Systems, Data Acquisition, Sensors, PCB Design

---

### 🤖 Smart-Auger Multi-Pet Identification & Dispensing System
> *Precision control meets intelligent sensing — because every system deserves a smart brain.*

Engineered an intelligent automated pet feeder that uses **multi-pet identification** to dispense the correct food portion to the correct animal. The system combines embedded microcontroller logic, sensor fusion, and mechanical actuation through an auger dispensing mechanism. The result: a closed-loop, autonomous feeding system with real-world reliability constraints — a mirror of how control systems operate in automotive and industrial applications.

**Stack:** Embedded Systems, C/C++, Sensors, Industrial Controls, PCB Design

---

### 🌐 F1 Planner Web App
> *Strategy is as important as speed — so I built a tool to plan both.*

Developed a **Formula 1-themed web application** that allows users to plan, visualize, and interact with F1 season data. The app reflects my deep knowledge of the sport and my ability to translate passion into functional, user-facing software. Designed with clean UI/UX principles, dynamic data rendering, and a motorsport aesthetic that makes it feel native to the paddock.

**Stack:** JavaScript, HTML/CSS, PHP, SQL, Web Development
